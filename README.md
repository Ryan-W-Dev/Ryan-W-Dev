## Featured work

### Smart Brain · Full-stack image detection

Detect people in images uploaded from a device or submitted by URL, with user accounts and a persistent leaderboard.

- **End-to-end account flows:** registration, HTTP-only sessions, editable profile pictures, and email password recovery with expiring, single-use tokens.
- **Connected backend:** an Express API integrates Hugging Face inference and PostgreSQL; Vercel, Neon, and Resend support hosting, data, and email delivery.

**React · Node.js · Express · PostgreSQL · Vite**

[Try the app](https://smartbrain.ryanwynn.dev) · [Explore the code](https://github.com/Ryan-W-Dev/Final_Project-SmartBrain)

An extreme-sports-inspired portfolio that pairs native scrolling with a coordinated freefall entrance, card journey, and visor reveal.
