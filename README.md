## Featured work

### Smart Brain — full-stack image detection

An application that detects people in images submitted by URL or uploaded from a device, with user accounts and a persistent leaderboard.

- **Account flows:** registration, sign-in, HTTP-only sessions, and email-based password recovery with expiring, single-use reset tokens.
- **Image interactions:** device uploads, URL-based detection, and editable profile pictures with save/cancel previews.
- **Persistent data:** PostgreSQL stores accounts and successful detection totals, with rankings calculated from user activity.
- **Service integration:** an Express API connects the client to Hugging Face inference, while keeping API credentials and database access on the server.
- **Deployment:** Vercel hosts the application, Neon provides PostgreSQL, and Resend handles password-reset emails.

**Built with:** React · Vite · Node.js · Express · PostgreSQL · Hugging Face · Resend

[Try Smart Brain](https://smartbrain.ryanwynn.dev) · [Explore the code](https://github.com/Ryan-W-Dev/Final_Project-SmartBrain)

### Interactive portfolio — creative frontend engineering

An extreme-sports-inspired portfolio that combines native scrolling with coordinated animation and a responsive layout.

- **Motion and interaction:** GSAP ScrollTrigger coordinates the freefall entrance, card journey, and visor reveal.
- **Accessibility considerations:** semantic components and reduced-motion alternatives keep the experience focused on the content.
- **Performance work:** optimized WebP artwork, responsive image loading, and decorative motion that pauses when hidden or offscreen.
- **Maintainability:** reusable Astro components, strict TypeScript configuration, and scoped animation cleanup.

**Built with:** Astro · TypeScript · CSS · GSAP · Vercel
