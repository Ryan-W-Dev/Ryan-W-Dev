## Selected work

### Snapback

A receipt and reimbursement application for capturing documents, reviewing expenses, and preparing claims.

- Photo and PDF receipt uploads, document previews, and parsing for supported flight tickets.
- Receipt fields and line-item extraction with Microsoft Azure AI Document Intelligence, with uncertain values flagged for review.
- Supabase authentication, PostgreSQL records, private file storage, and Postmark authentication emails.
- Expense folders, submission tracking, currency conversion, and CSV and company Excel-template exports that preserve formulas and formatting.
- Automated checks for receipt parsing, PDF handling, and exports, with deployment through GitHub and Vercel.

`React` `TypeScript` `TanStack Start` `Supabase` `Azure AI Document Intelligence` `PDF.js` `ExcelJS` `Vercel`

[Visit Snapback](https://usesnapback.app/)

### Client returns and approval dashboard

A private client application for managing product returns from intake and inspection through manufacturer review, shipment, and closure.

- A central dashboard with searchable records, filters, and return-status tracking.
- Manufacturer approval and rejection workflows, separate staff and reviewer permissions, multi-factor authentication, and audit history.
- Authenticated server endpoints, database access rules, and private storage for supporting documents.
- Shipment statuses, dates, and tracking references, with Excel and CSV exports.
- Automated application, database, and authentication checks, plus GitHub Actions and Vercel deployment.

`Next.js` `React` `TypeScript` `Supabase` `PostgreSQL` `ExcelJS` `GitHub Actions` `Vercel`

*Client identity and application access are private.*

`Next.js` `React` `TypeScript` `Tailwind CSS` `HubSpot` `NextAuth` `Playwright` `Vercel`
